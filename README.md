# Natrulir — Organic Living Microgreens & Eco Grow Kits Storefront 🌿

Natrulir is a modern, eco-luxe E-Commerce web application built with React, Vite, and Tailwind CSS for selling living organic microgreens, DIY ceramic grow kits, heirloom seeds, and superfood powders.

## 🚀 Key Features

- **Botanical Aesthetic & Design**: Rich organic color palette (`#1E3A27`, `#2B5737`, `#A3D977`, warm cream `#EFEAD8`) with elegant typography (*Playfair Display* & *Plus Jakarta Sans*).
- **Interactive Catalog**: Filter by category (*Live Microgreens, Grow Kits, Organic Seeds, Superfood Blends, Accessories*), sorting, and search.
- **Product Details & Nutrition**: Deep-dive modals with harvest times, taste profiles, and nutritional highlights (Sulforaphane, Vitamin C, Zinc).
- **Slide-Over Basket & Coupons**: Interactive cart with free shipping thresholds, promo codes (`GREEN10`, `HARVEST20`), and quantity adjusters.
- **Seamless Express Checkout**: Complete order placement with address collection, cash-on-delivery or online payment options, and confetti celebration.
- **Real-Time Live Order Tracker**: Real-time harvest and dispatch status tracking using order IDs (e.g. `MG-2026-XXXX`).

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS + PostCSS
- **Icons**: Lucide React
- **Animations**: Canvas Confetti

## 🏃 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```
